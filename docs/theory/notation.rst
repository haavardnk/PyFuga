Notation*
=========

.. note::
 
    This section lists the notation used throughout the Fuga theory documentation. It is not 
    exhaustive, but is a work in progress and will be expanded over time.

.. glossary::

   :math:`U_i`
      Mean velocity component in direction :math:`i`.

   :math:`P`
      Pressure per unit density.

   :math:`K`
      Eddy viscosity.

   :math:`f_i`
      Forcing from the actuator disc.

   :math:`z_0`
      Surface roughness length.

   :math:`z_i`
      Boundary-layer (capping inversion) height.

   :math:`u_*`
      Friction velocity.

   :math:`L`
      Monin–Obukhov length.

   :math:`\phi_m`
      Stability correction function for momentum.
